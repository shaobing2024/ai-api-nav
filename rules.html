排序与收录规则

了解我们如何评估和展示 API 中转服务商

评分维度

价格竞争力（30%）

模型单价是否低于市场平均水平，是否有隐藏费用，充值倍率是否合理。

稳定性（25%）

接口可用性、首字响应时间、高峰期是否稳定、是否有 SLA 保障。

社区口碑（20%）

用户评价、避雷信息、跑路历史、客服响应速度。

模型覆盖（15%）

支持的模型种类是否齐全，更新速度是否跟得上官方节奏。

用户体验（10%）

文档完善度、支付方式多样性、后台管理体验。

收录标准

必须满足：

  • 提供真实可用的 API 中转服务
  • 有明确的定价和充值方式
  • 支持主流大模型（OpenAI / Claude / Gemini 等）

加分项：

  • 国内直连，无需魔法
  • 支持人民币充值
  • 提供企业发票
  • 有完善的开发者文档

排序规则

默认排序：综合评分从高到低

赞助置顶：赞助商家在所属分区内优先展示

新站保护：新收录站点在"新站上榜"专区展示 30 天

动态调整：评分每月根据社区反馈和实测数据更新
